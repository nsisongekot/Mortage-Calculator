# Mortage-Calculator
A responsive Mortgage Repayment Calculator built with HTML5, CSS3, and Vanilla JavaScript.

This application allows users to calculate both Repayment and Interest Only mortgages while providing instant form validation and a responsive user experience.

Features
Calculate monthly mortgage repayments
Calculate total repayment over the mortgage term
Support for:
Repayment Mortgage
Interest Only Mortgage
Form validation
Clear All functionality
Responsive design for desktop and mobile
Interactive hover and focus states
Built With
HTML5
CSS3
JavaScript (Vanilla JavaScript)
Flexbox
Mobile-first responsive design principles
What I Learned
During this project, I learned how to:

Manipulate the DOM using JavaScript
Handle form submission using Event Listeners
Validate user input
Work with mathematical formulas in JavaScript
Use conditional statements (if...else)
Calculate mortgage repayments
Display dynamic content on the page
Reset forms using JavaScript
